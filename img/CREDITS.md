## Imágenes generadas para destinos

`guilin.webp` se generó con la herramienta integrada de generación de imágenes de OpenAI, usando como referencia visual el paisaje indicado en el feedback, y se optimizó a WebP de 1200 × 800 px para esta landing.

`shaolin.webp` se generó con la herramienta integrada de generación de imágenes de OpenAI, usando como referencia visual la práctica grupal de artes marciales indicada en el feedback y el tratamiento editorial de `guilin.webp`, y se optimizó a WebP de 1200 × 800 px para esta landing.

`istanbul.webp` se generó con la herramienta integrada de generación de imágenes de OpenAI, usando como referencia visual la mezquita de Ortaköy y el puente sobre el Bósforo indicados en el feedback, más el tratamiento editorial de `guilin.webp` y `shaolin.webp`, y se optimizó a WebP de 1200 × 800 px para esta landing.

`hongkong.webp` se generó con la herramienta integrada de generación de imágenes de OpenAI, usando como referencia visual el estanque ajardinado y el skyline urbano indicados en el feedback, más el tratamiento editorial de las imágenes de destino ya reemplazadas, y se optimizó a WebP de 1200 × 800 px para esta landing.

`tibet.webp` se generó con la herramienta integrada de generación de imágenes de OpenAI, usando como referencia visual el Palacio Potala sobre la trama urbana de Lhasa indicado en el feedback, más el tratamiento editorial de las imágenes de destino ya reemplazadas, y se optimizó a WebP de 1200 × 800 px para esta landing.

`beijing-hero.webp` se generó con la herramienta integrada de generación de imágenes de OpenAI para el hero, usando como referencia visual la Puerta de Tiananmén indicada en el feedback y el tratamiento editorial de las imágenes de destino ya reemplazadas. Se corrigieron la arquitectura y las inscripciones históricas antes de optimizarla a WebP de 1200 × 800 px.

## Imágenes generadas para las modalidades

`modalidad-acompanadas.webp` y `modalidad-flexible.webp` se generaron con la herramienta integrada de generación de imágenes de OpenAI y se optimizaron a WebP de 1200 × 800 px para esta landing.
